About the Project

A simple Student Report Card program built using Core Java.

Features

Takes marks for five subjects as input.

Calculates total marks.

Calculates overall percentage.

Displays subject-wise PASS/FAIL status.

Displays the final result based on passing criteria.

Concepts Used

Java Arrays

Methods

For Loops

If-Else Statements

Scanner Class

printf() Formatting

Passing Criteria

Minimum 27 marks in each subject.

Minimum 33% overall percentage.

How to Run

Compile Main.java.

Run the Main class.

Enter marks for five subjects.

Author

Created as a Core Java practice project.
